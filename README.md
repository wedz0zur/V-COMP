🛒 Магазин ПК-техники (Vue 3 + Pinia)
Этот проект — веб-приложение на Vue 3, которое использует API для загрузки данных о товарах.

📌 Основные возможности
-Главная страница с общей информацией.
-Каталог товаров с динамическим отображением списка.
-Модальное окно с подробной информацией о товаре.
-Добавление в корзину и управление количеством товаров.
-Корзина с возможностью удаления и оформления заказа.
-Избранное — добавление товаров в список понравившихся.
-Страница избранных товаров для быстрого доступа к отложенным товарам.
-Регистрация с валидацией, данные сохраняются в localStorage.
-Страница профиля, где данные пользователя загружаются из localStorage.


🚀 Технологии
Vue 3 — основа проекта.
Pinia — управление состоянием.
Vue Router — маршрутизация.
localStorage — сохранение данных пользователя.
