# 🛒 Магазин ПК-техники (Vue 3 + Pinia)

Этот проект — современный интернет-магазин ПК-техники, разработанный на **Vue 3** с использованием **Pinia** для управления состоянием. Мы создали удобное веб-приложение, которое позволяет пользователям просматривать каталог товаров, фильтровать их, изучать подробности в модальном окне, добавлять товары в корзину или избранное, а также регистрироваться и управлять профилем. Данные о товарах загружаются через API, а пользовательские данные сохраняются в `localStorage`.

## 📌 Основные возможности

- **Главная страница** с общей информацией о магазине.  
- **Каталог товаров** с динамическим отображением списка и фильтрами (по цене, объёму ОЗУ и другим параметрам).  
- **Модальное окно с деталями товара**:  
  - Компактный дизайн (высота 60vh, без скроллбара).  
  - Отцентрированное изображение (по вертикали и горизонтали).  
  - Визуальная обратная связь: галочка в кнопке "В корзине" после добавления.  
  - Единообразный стиль рейтинга ("4.5 ★") в карточках и модальном окне.  
- **Корзина**:  
  - Добавление товаров с управлением количеством.  
  - Удаление товаров и оформление заказа.  
- **Избранное**:  
  - Добавление товаров в список понравившихся.  
  - Отдельная страница для быстрого доступа к избранным товарам.  
- **Регистрация и профиль**:  
  - Регистрация с валидацией, данные сохраняются в `localStorage`.  
  - Страница профиля с данными пользователя, загружаемыми из `localStorage`.  
- **Страница 404** для обработки несуществующих маршрутов.  
- **Адаптивность**: Интерфейс полностью адаптирован для мобильных устройств.

## 🚀 Технологии

- **Vue 3** — основа проекта.  
- **Pinia** — управление состоянием (корзина, избранное, фильтры).  
- **Vue Router** — маршрутизация между страницами.  
- **axios** — работа с API для загрузки данных о товарах.  
- **localStorage** — сохранение данных пользователя (регистрация, корзина, избранное).  
- **CSS Flexbox** — для адаптивной вёрстки и центрирования элементов (например, изображения в модальном окне).  
- **Vite** — сборка и горячая перезагрузка для быстрой разработки.

📋 Дополнительно
Проект оптимизирован для производительности: используется ленивая загрузка изображений с помощью атрибута loading="lazy", а также спиннеры для индикации загрузки.
API-запросы обрабатываются с помощью axios, с поддержкой обработки ошибок через try-catch.
Состояние корзины и избранного сохраняется в localStorage, чтобы данные не терялись при перезагрузке страницы.
